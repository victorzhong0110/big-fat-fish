# 游戏像素模型

18种模型由 `src/v2/preview/characters.js` 手工定义，使用40×40整数网格、统一描边和独立身体/手脚/道具，不是原图裁切或缩放。`npm run generate:characters`生成首页静态SVG，战斗直接调用同一代码模型绘制，不加载参考试稿。

待机呼吸/眨眼、移动步态、左右朝向、攻击抬手/抬盆、受控静止和受击闪白只影响表现，不改变战斗判定。DeepSeek无盆无加号，作为原“替身进程”伙伴的外观，保留原诱饵技能；Claude统一棕色螃蟹，不带绿框，阶段影响外壳；Grok首领保留火箭。

BSOD和Null Signal仅提供模型展示，未新增敌人行为。原试稿保留在文档目录，不作为运行时贴图。新模型不声称与参考逐像素一致。
