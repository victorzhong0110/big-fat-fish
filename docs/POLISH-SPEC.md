# 大肥鱼历险记 · 视觉质感与打击感精修规格（POLISH SPEC）

> **目标**：在不推翻现有架构与玩法的前提下，彻底消除“网页套壳感”与“程序几何块粗糙感”，把整体观感打磨到精品独立像素游戏水准。
> **前置要求**：必须严格遵守 [AGENT.md](../AGENT.md) 与 [BRAND_GUIDE.md](BRAND_GUIDE.md) 的主题与 Q 弹粗黑边像素风约束，**禁止破坏 `src/v2/domain/` / `engine/` 确定性逻辑与 `approved-art.json` 已锁定原图**。

---

## Polish 1：像素字体、立体 UI 边框与海克斯稀有度卡片

1. **接入清晰可读的像素字体**：
   - 在标题、数字（HP / Benchmark 跑分 / 伤害跳字）、按钮和短标签上统一使用清晰开源像素字体（优先 **Fusion Pixel 缝合像素字体**，本地打包进 `public/fonts/` 避免断网回退），长段说明文字保持清晰无衬线体以确保可读性。
   - 同步应用到 Canvas 绘制文本（`ctx.font`）。
2. **UI 面板立体像素质感（消除单层纯色平扁感）**：
   - 为 `src/lobby.css` 和 `src/v2-preview.css` 的所有面板、按钮、卡片增加**像素游戏经典的“内高光 + 内暗边”立体压边**（如顶部/左侧 `inset 0 3px 0 rgba(255,255,255,0.18)` + 底部/右侧 `inset 0 -3px 0 rgba(0,0,0,0.28)`），悬停时轻微提亮并上浮 `1px`，按下时真实下沉 `2px`。
   - **修复桌面战斗 `.toast` 遮挡目标行**：将 `src/v2-preview.css` 中桌面端 `.toast` 的 `top` 从 `112px` 调整为 `156px`（或动态置于 `.hud` 下方），确保 `npm run test:v2:interface` 全绿。
3. **海克斯三选一稀有度视觉升级**：
   - **白银（常见）**：冷银像素边框 + 浅蓝微光底纹。
   - **黄金（进阶）**：暖金像素边框 + 斜向像素高光条。
   - **棱彩（传说）**：青紫金渐变脉冲像素边框 + 四角小星芒装饰，三选一弹出时带轻快弹跳入场动画。

## Polish 2：海床与小窝场景美术升级（告别程序几何画）

1. **接入统一风格的 CC0 像素地形与物件素材**：
   - 将原本用 `fillRect` / `arc` 程序硬画的**珊瑚礁、木箱、宝箱、开源盲盒、小窝餐桌、靶桩、海草**，替换为风格统一的 **Q 弹粗黑边像素贴图（放入 `public/art/props/`）**，渲染保持 `imageSmoothingEnabled = false`。
   - 若部分物件暂时保留 Canvas 像素绘制，必须按 `16×16` / `32×32` 真实像素网格绘制**受光面、暗部阴影、高光点与 `2px` 深色描边**，绝不使用粗糙的单色矩形。
2. **水下环境氛围层（低干扰、高质感）**：
   - **海床焦散光斑（Caustics）**：在 `view.js` 最底层（实体之下）叠加一层极低透明度（`alpha 0.04–0.07`）缓慢漂移的青白色水波光网，瞬间拉出“水下”通透感，同时不影响红色预警圈与弹幕辨识度。
   - **环境微粒与动态海草**：海床与小窝房间加入少量缓慢上浮的半透明小气泡、轻度摇曳的多节像素海草，让静止画面也有呼吸感。

## Polish 3：战斗爽感与交互 Juice 精修

1. **伤害跳字分级与弹跳曲线**：
   - 普通命中：暖白小号像素数字，短抛物线上浮渐隐。
   - **暴击 / 弱点命中**：放大 `1.45×` 金橙色粗描边像素数字，带开局 `1.25→1.0` 弹性缩放动画。
   - 小窝试射靶桩同步享受完整伤害跳字、命中火花与靶桩受击晃动反馈。
2. **泡泡炮开火与命中细节**：
   - 开火瞬间在泡泡炮口位置生成 1 帧紧凑像素炮口闪光（`#A1EAFA`）+ 2 粒飞溅小水花。
   - 子弹轨迹加极淡的 2 帧水泡拖尾。
3. **Boss 登场与重要节点仪式感**：
   - Boss 现身瞬间在屏幕上方弹出带**阵营色像素横幅**（如 ChatGPT 翠绿 / Claude 陶土橙 / Grok 荧光绿）的轻量入场条（1.8 秒自动收起，不遮挡玩家操作）。
   - 探索模式撤离倒计时最后 1 秒加强音效与气泡收缩汇聚动画，撤离成功弹出清晰的战利品结算清单卡片。

## Polish 4：标题界面图标化、资源分离与真滑动滑块

1. **资源显示与功能按钮彻底分离**：
   - **算力卡与零件**：做成独立于功能按键的轻量资源胶囊栏（无按压阴影、不可点击），格式为 **`[像素/开源图标] 数字`**（如显卡图标 + 数字、零件齿轮图标 + 数字）。
   - **功能入口全部图标化**（图鉴、模组、设置、继续检查点、小窝家园、AI 科技树、成就）：
     - 使用辨识度高的**开源像素风图标**（或统一 `16×16` 像素矢量图标），**去掉所有文字方块**；**手机端也不保留小字标签**，保持画面极简。
     - **桌面端悬停淡入说明**：鼠标悬停或键盘聚焦图标时，在图标旁边平滑淡入说明性小标题（如 `设置`、`图鉴`、`小窝家园`、`AI 科技树`、`成就 N`），左栏向右淡入、右栏向左淡入。
2. **右下角三档模式切换改成“真滑动滑块”**：
   - 外层做成带内阴影的深色圆角轨道（四周留 `4px` 内边距）。
   - 内部放置一个**独立的圆角亮色滑块（Thumb）**（带 Q 弹高光边与 `cubic-bezier(.34,1.56,.64,1)` 回弹过渡），切换 `剧情 | 探索 | 无尽` 时滑块在轨道中真实平滑滑动，文字浮在滑块之上。
3. **收拢右下角多余方块**：
   - 将 `三连战`、`Free 教学`（及“再走一次 Free 教学”）从首页右下角移入左侧设置/高级选关或 Benchmark 选关页内，让标题页右下角只保留**一条干净的三档滑块 + 一颗 `▶ 选择难度` 主按钮**。

## 交付与验收标准

- 每个 Polish 阶段结束后均需运行：
  ```bash
  npm run check:v2
  npm test
  npm run build
  ```
- 若改动涉及 UI 布局或字体大小，需额外在无头浏览器下检查桌面（1280×800）与手机横竖屏（844×390 / 390×844）无文字溢出与元素遮挡。
