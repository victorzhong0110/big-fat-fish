## 3. 关键实验数据（**以机器字段为准**）

### 3.1 两档机器人对照（**同一 build，同种子 1000/1037/1074，同 250 游戏秒上限**）

| build | smart（会读对症） | good（按稀有度挑） |
|---|---|---|
| **保底机制之前**（`src/systems/draft.js` 改动前的 mtime 之前） | 3 局：**1 次真通关**（wave20 `victory`, hp9/6）、到第 20 波 **3/3**、avg **21.5** 波 | 2 局：**0 通关**、到第 20 波 **0/2**、avg **9.5** 波、死第 **12 / 7** 波 |
| **保底机制之后** | 3 局：`(seed1000,20,over,hp0,kill546/595)` `(seed1037,22,timeout,hp6,672/733)` `(seed1074,20,victory,hp9,658/662)` | ✅ **1 局补跑成功**（冻结快照上跑，端口 8917）：`(seed1000,12,over,hp0,kill17/199)` |

> ★ **同种子直接对照（保底后的 build，同一份 dist）**：
> **seed 1000 —— smart 打到第 20 波（546 杀 / 595 生成，击杀率 0.92）；good 死在第 12 波（17 杀 / 199 生成，击杀率 0.09，怪堆满身）**。
> 也就是说：同一个种子下，**不会读对症的那一档是字面意义上「被怪淹没」，会读对症的那一档在清场**。

> **口径说明（重要）**：上一行两组数字**出自同一份 build**——
> `src/systems/draft.js`（手段保底）的 mtime 是 **20:22:23**，而 good 报告是 18:57、smart 报告是 20:09，**都在保底之前**。
> 所以「smart 有 1 次通关、good 0 次」**是同 build 的合法对照，结论成立**。
> 而**保底之后**只有 smart 的浏览器数据 + 离线对照（见 3.2），good 的浏览器数据**没有补上**。

### 3.2 机制纯度：它自己把代价写了下来（离线 3000 局，同 build）

| | 无保底 | 有保底（换收益最低的那张） |
|---|---|---|
| smart 最终倍率 | 2.271 | **2.425** |
| good 最终倍率 | 1.627 | **1.956** |
| smart 比 good 高（最终倍率） | 39.6% | **24.0%** |
| smart 有效 DPS 高 | 33.6% | **21.2%** |

它明确写了这是**取舍**：「**可玩性优先于机制的纯度** —— 一个『抽到就赢、抽不到就死』的机制，
对真人玩家来说不是难度，是抽奖。」

## 4. 这一轮真正有价值的三个技术成果

### 4.1 把「对症」从提示变成机制（§23）
克制 = 伤害 **×2.5**，判定接在**唯一的扣血入口**（子弹穿体 ⇒ 按被打的那只算）；
倍率曲线是**凸**的（`1 + 1.5 × 命中占比²`）⇒ 凑齐手段远比单张值钱；
四种手段的命中集合**互不重叠**（单一手段覆盖 8%–61% 血量，凑齐约九成）；
**深化也能给手段**（抽不到对症牌时有唯一出口）；
手段牌同时带伤害收益 ⇒「对症」与「强」不再二选一。

### 4.2 面板说人话（§25）
新纯模块 `src/systems/relicValue.js` ⇒ 每张候选牌显示「**伤害 +20%**」/「**不提高伤害**」，
转化型标「**（满层估计）**」不把理论值当保证。
并修掉一个**面板在撒谎**的口径 bug：「暴击率 +8%」在旧口径下收益算成 0 ⇒ 面板会说「不提高伤害」；
期望 DPS（含暴击期望）提到 `upgrades.js:20` 的 `expectedDps()`，覆盖度/抽卡估值/bot 评分**共用这一份**。

### 4.3 抽卡「手段保底」（§26）

**先量问题多大再改**：实测「旧行为下 **24.5%** 的第一章抽卡里一张手段牌都没有」⇒ 新行为 0.0%
⇒「这不是难度，是**机制被运气否掉**」。
实现（`src/systems/draft.js:78-93`）：候选里至少一张带手段的牌，
但**只保证看得见不保证拿得到**、**池里没有不强塞**、**换掉收益最低的那张**（随便换一张会让普通 DPS 掉 ~17%）。

### 4.4 面板不冤枉一张好牌（§27，第十二轮）
`relicValue()` 现在把**前提写出来**而不是换一个数：
- 有伤害收益 → 「伤害 +X%」
- **只给暴击伤害、手里没暴击率** → 「**暴击伤害 +70%（要配暴击率）**」
- 真的什么也不加 → 「不提高伤害」
- 转化型 → 「伤害 +X%（满层估计）」

它自己的验证：`vitest 343/343`（24 文件，新增 1 条「条件性收益不能被写成『不提高伤害』」）、
WebGL 134/134；**Canvas 本轮未跑，它自己标注「不能算验过」**。
本轮**只改文案、没改任何数值** ⟹ 第九~十一轮的实测数据继续有效。

## 5. 遗留问题（按严重度）

### 🔴 P0：HUD 顶栏文字重叠 —— **连续 24 轮未修**
独立复验（步骤 06，**在最终交付的单文件上实测**）：**13 组重叠**，
最严重的 `#wave × .hearts` 占小元素 **99%**、`#dew × #fire-level` 64%、`#hero × .fire-level` 71%。

根因（`src/styles.css`）：`.relics` 的 `width: 100%` 抢整行；`.tag` 无 `min-width:0/overflow:hidden/text-overflow:ellipsis`。
**修法（已用注入实验验证：13 组 → 0 组）**：
```css
.relics   { width: auto; flex: 0 1 auto; }
.hud-group{ flex: 0 1 auto; }
.tag      { min-width: 0; overflow: hidden; text-overflow: ellipsis; }
```
**讽刺点**：同一个 agent 在第 11 轮刚用**截图**抓出并修好了另一处栅格碰撞（`.threat-row` 的
`counter` 格与 `desc` 挤在一起，浏览器试玩 134/134 全绿却只有截图看得见），
却把 HUD 这个同类问题留了 24 轮 ⇒ **这是优先级问题，不是能力问题。**

### 🔴 P0：难度档位**从未经过真人验证**
需求曲线这一轮抬了两次、台阶形状改过一次，**全部只经过机器人**，
而机器人的走位与自动瞄准都是完美的。它自己写下：
- 「**不会读对症的人几乎没有活路**」（good 死于第 7 波 = 第二章第一波）；
- 「**在真人试玩之前，不要再往上加难度了**」。

### 🟡 P1：口径纪律（两处，均已在报告中按机器字段更正）
1. **agent 自己的表格**把 `state=timeout`（250 秒内没打死终局 Boss、HP 还剩 6/7 与 2/7）写成
   「**通关主线 2/2**」—— 报告字段是 `victories: 0`、`reachedWave20: 2`。
   （`src/systems/run.js` 的 `isFinalBossEnemy` 按**出生波**判定 ⇒ 只有打死才 `runState='victory'`。）
2. **`summary.deathCauses` 对 timeout 局记的是「最后一次伤害来源」**（写在掉血路径 `GameScene.js:1951`），
   对 over 局才是真死因 ⇒ 两档并排比「死因」不是同一口径。

### 🟡 P1：**我自己的一次误判**（已更正并记录在案，同族第二条）
我在 20:04 / 20:13 两轮说「good 未在新 build 上重跑 ⇒ 两档不在同一份代码上 ⇒ 结论不成立」。
**这个判断是错的**：核到 `draft.js` 的 mtime 后确认两份报告都在保底之前 ⇒ **同 build，结论成立**。
（教训同族：**先分清是产品错还是测量方法错**，这一条对我自己同样适用。）

### 🟡 P1：保底之后的 `good` 浏览器对照**缺失**
我的补跑两次都被 SIGKILL 杀掉（与 agent 同机并发）⇒ 收尾时**没有**同 build 的保底后 good 浏览器数据。
只有 agent 的保底后 smart（3 局）与离线 3000 局的对照。

### 🟢 P2：它自己列的下一轮优先级（照搬，未被我干预）
1. 真人试玩定档（**必做**）
2. 用 `retune2` 按新数据重标需求曲线（保底让 DPS 降了 13–15%）
3. 实测「连击的实际平均层数」（现在的 3 层是**拍的**，它自己承认「没有实测的保守值只是另一种形式的拍脑袋」）
4. 把「面板估值」与「机器人目标函数」**解耦**（现在共用一个数 ⇒ 改估值就改写机器人行为）
5. 让「机动」不再一家独大（48%–61% 血量命中）
6. 条件性收益的显示（「致命芬芳」被写成"不提高伤害"，冤枉了它）
7. Boss 各自难度曲线 / 敌方弹幕速度 / 遗物分级
