# 大肥鱼历险记 · 品牌与美术界面指南（BRAND GUIDE）

> 本文档为全项目**唯一视觉与主题标准**，所有界面、像素素材、特效与文案改动均须遵守。详细工程实施拆解见 [UI-ART-OVERHAUL-SPEC.md](UI-ART-OVERHAUL-SPEC.md)。

---

## 一、品牌核心与绝对禁区

* **唯一锁定主题**：**AI 圈黑话梗的深海像素轻松爽游**（DeepSeek 大肥鱼 × ChatGPT / Claude / Grok）。
* **核心情绪**：轻松、搞笑、明快、爽快。
* **绝对禁区**：
  1. **禁止跑偏世界观**：绝不出现“深夜食堂”“月潮电台”“航程日志”“修船厂”等文艺航海设定。
  2. **禁止画风拼贴**：绝不混用高清二次元插画、写实海底照片、3D 拟物道具。
  3. **不强行全员硬件化**：世界是轻松有趣的深海游乐场——**大白饭就是大白饭**、**珊瑚就是珊瑚**，不需要把石头和海草全改成电脑机柜或网线。
  4. **不做廉价硬玩梗**：禁止在角色头顶随机刷无意义废话气泡，AI 梗要融进玩法机制与视觉反馈中。

## 二、统一画风与色彩系统

### 1. 画风标准
* **主画风**：**Q 版粗黑边卡通像素风**（圆角、粗黑描边、按钮按压弹跳感，对齐 `public/art/characters/` 现有立绘，渲染关闭抗锯齿 `imageSmoothingEnabled = false`）。
* **素材来源策略**：海床地砖、珊瑚、木箱、气泡、UI 边框和小图标**优先从开源/CC0 像素素材库获取**（如 Kenney、OpenGameArt、itch.io CC0 像素包），再微调色调融入深海；**不必全部重新生成**。

### 2. 配色方案（Color Palette）

| 角色 / 层级 | 建议色值 | 用途说明 |
|---|---|---|
| **海床底色（低对比）** | `#0F2C3D` ~ `#163D4E` | 深海青蓝底色，纹理只比底色亮/暗 5%–8%，绝不抢戏 |
| **DeepSeek（主角）** | `#5B7CFF` / `#75D7ED` | 亮海蓝与泡泡青，用于玩家光环、能量弹、主按钮高亮 |
| **ChatGPT 阵营** | `#10A37F` | 标志性翠绿，用于 GPT 阵营血条、火花与弹幕边框（`Luna → Sol → Astra`） |
| **Claude 阵营** | `#D97757` | 陶土橙，用于 Claude 螃蟹、封禁框与预警线（`Haiku → Sonnet → Opus`） |
| **Grok 阵营** | `#00C875` | 荧光绿，用于 Grok 机器人与火箭尾焰 |
| **大白饭 / 提示文字** | `#FFF8E7` / `#F4EFE0` | 暖米白，保证在深蓝海面上清晰可读 |
| **危险预警 / 高难阶梯** | `#FF6B6B` / `#F4B77F` | 高亮红橙，仅用于 Boss 大招范围、高 Benchmark 档位与危险预警 |

## 三、五大视觉模块总览

1. **大厅主页**：干净像素海洋背景（缓慢气泡 + 轻摇海草）+ 正中**大肥鱼元素定制像素艺术字标题** + 右上角**小窝家园/科技树入口** + 右下角**三档模式滑槽（`剧情 | 探索 | 无尽`）与进入按钮**。
2. **Benchmark 难度页**：纵向分栏——右侧纵向滚动 **Benchmark 1–15 纯数字跑分列表**（每 5 级对应 `Luna → Sol → Astra` 升阶），左侧展示敌方模型阵容与词缀，左下显示奖励倍率与强度。
3. **局内战场与 HUD**：低对比像素海床 + CC0 像素珊瑚/宝箱/气泡撤离点，接入 `bsod.png` / `null-signal.png`；《元气骑士》式极简四角 HUD + 主角脚下状态环，严禁左下角大弹窗遮挡。
4. **小窝家园**：可操作大肥鱼自由游动的像素海底房间，含已解锁伙伴（按 `F` 底部弹出经典像素 RPG 对话框）、**试射靶桩**、**大白饭小餐桌**、科技树终端与模组/图鉴台。
5. **《文明6》式横向扩展科技树**：横向 4 个 AI 梗时代（`预训练 → 微调 → 对齐 → 全量涌现`）、多线分叉与跨线双前置、正交折线箭头与前置路径高亮。
