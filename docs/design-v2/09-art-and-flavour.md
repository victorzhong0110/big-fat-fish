# 09 · 像素大肥鱼、参考图与社区梗命名

本章是给Grok/美术实现者的交接，不是声称已完成精灵或接入音源。两张用户参考原图位于本次设计讨论附件，仓库只记录文字造型要求，不包含原图；实现者需从用户获取原始参考，不直接把含背景截图当作游戏精灵。

## 1. 主角：拿铁盆的像素大肥鱼

用户参考附件：`7596314315b8c2b7e893794eeb815c18.jpg`（已在设计讨论中查看，未上传仓库）。

用户明确要这类像素社区形象。参考中的主要识别点是蓝紫长发/侧后发尾、呆萌小脸、白色头饰、深色服装，以及抱在身前的大灰色铁盆。主角应是这类Q版社区大肥鱼/鲸鱼娘形象；旧代码里单纯蓝色椭圆鱼身只作为历史占位，不是最终美术标准。

- 建议基础精灵64×64像素，清楚的深色像素轮廓，有限色阶；禁止运行时平滑缩放模糊成插画。整数倍率优先，采用nearest-neighbor，手机不为追求整数倍率裁掉重要战场。
- 铁盆是常驻视觉标志。MCP可表现为盆沿挂件/盆中工具、不同弹口与特效；不能换武器就把整个主角换成机器人或别的鱼。铁盆本身不默认提供格挡/近战/吸弹，这是美术要求，不新增玩法。
- 首批动画：待机、移动、射击/技能、冲刺、受伤、被禁锢/挣脱、倒下；先做4方向可辨的身体动画，瞄准/弹口仍可360°，后续补8方向。镜像不能把文字/单侧标志画反。
- 表情以笨笨的、关键时刻突然认真为主；LoRA完美时兴奋端盆，欠拟合发懵、过拟合僵硬；不同结果同时用文字/图标区分，不只换颜色。
- 角色碰撞锚点在身体中心/脚下投影的固定位置，毛发、头饰与铁盆装饰不扩大隐形碰撞；基础半径16保持可见脚底命中环核对。若美术尺寸要求改半径，必须同步所有碰撞/预警与验收，不能只放大图片。

## 2. GPT Pets与模型标签

用户参考附件：`image(20261024-183637).png`（已在设计讨论中查看，未上传仓库）。

截图明确七种：Codex、Dewey、Fireball、Hoots、Rocky、Seedy、Stacky。每种维持自己的轮廓与主要配色，不能都画成同一个小工人换色。Pro/Max5x/Max20x/API对应Astra/Sol/Terra/Luna（08），用脚底标记、简短模型名、状态挂件与攻击表现区别；模型档位不改成另一物种。
