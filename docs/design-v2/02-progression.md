# 02 · 算力卡技能树、小窝与永久成长

## 1. 技能树的边界

局外技能树点数统一叫“算力卡（GPU）”；5个算力碎片自动兑换1张算力卡，余额永久保留。技能树共30个节点，包括24个原有基础节点、07中的3个DSH特殊节点和本次新增的3个节点，全部单级购买，不再给每个节点塞10级微小百分比。小窝可免费重置整棵树，全额返还已花点数；不能在对局中购买或重置。当前出发所用技能树与DSH装配快照锁定到本局结束，读检查点不读取之后修改的局外树。

四条基础分支：干饭体魄、MCP熟练、技能调度、探索与伙伴。每条6节点：A→B，然后分成C/D，再汇入E→F。E要求C与D都已购买。原有基础节点的前置关系保持兼容。基础费用136张算力卡；DSH特殊节点另24张，旧树合计160张。新增重炮微调（4张，前置即插即用）、上下文吃撑（8张，前置饭后散步和稳定连接）、搜打撤专家（8张，前置默契训练和快速响应），全树合计180张算力卡。节点费用与效果如下；解锁效果不是当前背包里自动生成一件物品。

## 3. 经济与解锁

碎片与零件的局内获得/带回口径以 01 为准；局外树不增加碎片掉率或永久伤害复利。普通失败仍有进展，但快速开局立即自杀不应有固定补贴。正式冒险开局不发免费算力卡（Free首次教学奖励按07单独处理）；第一个节点费用低，实际探索一段即可购买。

零件用于设施以及永久装备/技能选择权。发现新武器/技能后，本局立即可用，结算时将图鉴“已发现”永久保留；在小窝花零件后才成为下次出发可选项。未永久购买不妨碍未来局中再次掉落。拾取/发现只触发一次图鉴事件，不能通过检查点重复兑换。

初始可选：泡泡接口、技能“断开连接”、伙伴“饭团”；其余项目在探索中首次出现后才可永久购买，费用见 03。

## 5. 居民、伙伴与任务

6 位伙伴的战斗能力见 03。它们既可以住在小窝，也可以被选作唯一助战。小窝任务每位一条，完成后永久解锁其出发选择，不另设关系值刷取。救助任务与专属收藏可放在可选支路，不挡主线。

## 6. 结算与存档一致性

结算由唯一 runId 提交一次：计算失败比例→加入碎片/零件→兑换算力卡→记录解锁→清除活动检查点→保存局外档。全部作为同一个版本化存储记录提交；不能先加货币再单独删除检查点。保存失败保留内存中的待提交结果并提示重试，不让玩家反复点击叠奖励。

图鉴/救助的即时持久化使用 stable discoveryId，与检查点快照分开去重。恢复旧检查点不撤销局外已记录发现，也不再次给资源。树只保存已购节点 id 与余额，启动验证前置和总花费；版本迁移时按旧成本全额返还被删除节点。
