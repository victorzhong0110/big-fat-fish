# 04 · 插件（Plugin）完整目录与联动规则

## 1. 获取、容量与抽取

插件是本局的规则强化，局末清空；不使用旧“遗物/对症标签”系统。01 指定等级触发暂停三选一。最多装备6种普通插件，每种最高2级；Pro自带5h限制是07定义的不占槽难度插件，同名不叠加；第二次选择同 id 升为 2 级，不再占槽位，不能重复触发两份同名效果。

候选 3 张 id 互异，只抽已实现、适用当前模式且未满级的条目；不按玩家当前强弱临时修改掉率。首个选择事件必含 1 级“蒸馏”，另外两张正常抽；只是看得见，不强迫选择。候选生成后存档保存完整候选和随机流，关闭面板或恢复不能重抽。

| 第几次选择 | 常见/进阶/传说权重 |
|---|---|
| 1–2 | 75 / 23 / 2 |
| 3–4 | 50 / 40 / 10 |
| 5 及以后 | 30 / 50 / 20 |

权重先抽稀有度，再在该档合法 id 中等概率抽取；空档按原权重对非空档重新归一化。未持有与可升级 id 同权。每局有 1 次免费整组三张重抽（消耗一次后永久记在本局），重新生成时优先避开刚才三张，池不足才复用；不加另一种货币。

满 6 种后，候选可出现升级或新插件。选择新插件时，明确预览并二次确认替换哪一种；取消返回原三张，不重新抽。移除旧插件时停止其后续触发，移除其常驻属性；已生成投射物/诱饵按生成时快照自然结束。移除“蒸馏”会冻结并禁用所有蒸馏属性/能力，重新获得时恢复本局既有进度，不能靠换出再装刷一次性奖励。玩家也可以“跳过”，获得一次仅治疗 8 的补给，满血也不转换资源；这是插件选择的明确代价选项，不是检查点效果。

## 2. 计算术语

- 基础武器命中：sourceKind=weapon_primary；只有主弹/该武器原生多弹参与，派生投射物和爆炸不参与，除非明写。
- W：武器单枚基础伤害（含品质、不含插件/技能树/暴击）；插件子伤害先算基础再统一套通用加成一次。
- 同一“射击”是一次攻击间隔产生的整组弹，而非每枚子弹。所有内置冷却用 tick，不受射速加成影响。
- “每 N 次命中”按真实造成正伤害的合法命中计数；免疫、护盾完全抵消的目标命中不累计；同一攻击对同一目标最多一次计数。
- 通用输出加成与武器伤害加成各自同组加算，组间相乘；暴击最后乘。射击间隔乘算，最低 0.025 秒；装备主动技能最低冷却 1 秒；移速加算后最高基础的 2.5 倍。后续效果不得突破 06 的触发预算。
- 下表“1级→2级”是替换参数，不是把两列叠加。没有写的属性不变化。卡面由这些参数生成。

## 6. 蒸馏：属性与技能来自谁

用户要求是获取对方的一部分属性、技能。这里不用“持有蒸馏就所有伤害提高”的抽象标签；玩家应看见来源、样本、学会的东西。

### 触发和归属

- 持有且启用时，敌人第一次死亡产生一个对应阵营样本；只要死亡 creditOwner=player，无论基础武器、插件、蒸馏、伙伴击杀均可获得。它是死亡事件奖励，不是可错过的地面经验物。
- 追兵/驻守/普通召唤怪可提供样本；ChatGPT 重置回响敌人不提供样本（05）。普通Claude蟹3样本、ChatGPT Pet/Grok Bot各1样本；Claude个体精英6样本、ChatGPT个体精英3样本，Grok精英群成员各1且无额外群奖励；Boss6样本，只归所属阵营，不获取 Boss 完整禁锢/重置能力。
- 没有持有时不积累历史样本；拿到以后从 0 起。移除后暂停积累且禁用能力，但保留已经积累的数值；重新装回不能重复升级奖励。
- 三条来源独立，各最多蒸馏 3 阶。样本自动转阶；溢出进入下一阶，到 3 阶后停止积累，不兑换大白饭/资源。

| 来源 | 每阶样本：插件1级 / 2级 | 1阶 | 2阶 | 3阶 |
|---|---|---|---|---|
| Claude | 6 / 4 | 护甲 +6；实际扣生命后生成 5 护盾持续 2 秒，内置冷却 10 秒 | 护甲总 +12；护盾变 8 | 护甲总 +18；护盾变 12 |
| ChatGPT | 6 / 4 | 学会追击泡：每 5 秒向 500 内最近敌人发 1 枚 8 伤追踪泡 | 同时 2 枚，各 8 伤 | 同时 2 枚，各 12 伤 |
| Grok | 10 / 7 | 移速+3%；每8次基础射击沿瞄准方向生成2只Bot虚影，移速240、持续2秒、每只接触首个敌人造成6伤后消失，内置冷却4秒 | 移速总+6%；每次3只虚影 | 移速总+9%；每次4只虚影 |

2级是更快成型，已有样本按新门槛立即结算，输出上限不另翻倍。阶数表的“总”替换旧值，不能累计成 +36 护甲或 +18% 移速。蒸馏护盾命名独立，护盾受击顺序见 06；护盾满挡时不触发新的蒸馏受伤盾。

追踪泡无目标时保留就绪状态，有目标才消耗冷却。Grok派生能力体现普通Bot的数量与追赶：基础射击计数满8且内置冷却就绪时释放Bot虚影，最多同时4只，已有虚影不够空位时只生成剩余空位数且照常消耗触发。虚影无碰撞阻挡、不受敌人攻击，只沿释放方向前进，不额外施放技能、掉资源或积累新的射击计数；sourceKind=distilled。普通Bot不会发火箭，所以不从它们蒸馏出Boss火箭。Bot虚影继承08指定的grok_passable低矮障碍通行，不穿高墙/边界。

HUD 展示三图标、当前阶、样本 `3/6`，获得阶时短播“蒸馏完成：Claude 护甲 / ChatGPT 追击泡 / Grok Bot虚影”。只首次获得一种能力弹一次小提示，不暂停战斗。

蒸馏也是入门构筑路线：打什么敌人就逐渐拿到它的一部分能力。它不是必选通关钥匙，不给 Boss 整套重置，不永久带出局。

## 7. 5h限制：严格的十秒伤害额度

采用滚动窗口，逐敌人/战斗 sourceId 独立记录 `(tick, budgetSpent)`。每次命中前移除 `tick<=currentTick-600` 的记录，剩余额度 `cap-sum(spent)`。首领本体、该首领发出的火箭/弹体/持续区域共用该首领 id；召唤小怪各有自己的 id，不能每发子弹都当新额度。

只有攻击已经合法命中、且未被闪避/无敌否决时才进入额度结算。设防御前伤害为 D、剩余额度为 R，则本次许可伤害 `A=min(D,max(0,R))`；A>0 才记账。之后对 A 计算护甲、定向减伤、护盾和生命。护盾吸收也会消耗额度，因此护盾可以把一只敌人的输出额度吃掉；玩家免疫期间未命中不消耗额度。

这一插件不对敌人伤害设置最小 1，额度耗尽可以为 0；不限制控制效果，不能靠额度为 0 免疫禁锢。普通受击保护会否决伤害，但控制是否生效按 05 的独立控制免疫规则处理。

暂停、检查点恢复、Boss 自身重置不会清空/加快额度；ChatGPT 本体 sourceId 跨所有重置保持不变。插件升 2级后沿用过去 10 秒已花额度，较低上限立即生效。移除后停止限制但记录已有额度，保留最近十秒历史；重新获得不重新发放额度，未持有时合法命中的防御前伤害也记历史，供重新启用计算。

示例：上限 18，t=1 秒命中 12，t=4 秒请求 10 只允许 6，t=9 秒允许 0；t=11 秒第一个 12 离开窗口，额度回到 12。与 Grok 群怪交战仍危险，因为每个 Bot 有独立额度。

## 8. 代表性组合与预期取舍

| 组合 | 能看到的打法 | 自然短板 |
|---|---|---|
| 并行调用 + 批量处理 + 扇面 MCP | 扇面铺场、触发范围爆破，清 Grok 群怪 | 远处单体命中率/射程 |
| 缓存命中 + 长上下文 + 流式 MCP | 持续盯住首领，输出越来越强 | 需要换目标/躲招时断档 |
| 蒸馏 + 工具链 + Agent 协作 | 射击产生Bot虚影、自动追击泡，主动技能与伙伴形成工具链循环 | 前期要收集样本，控制和封禁可打断 |
| 5h限制 + 缓存护盾 + 安全对齐 | 吃掉单体敌人的输出额度，顶住重击 | 群怪/禁锢仍有威胁，输出不自动增加 |
| 推测执行 + 卸载缓存 + 回旋 MCP | 冲刺穿场，尾流与回旋交错命中 | 切入时机与危险区域 |
| 混合专家 + 热插拔 + 两种 MCP | 换枪与双工具联动，随时切打法 | 需要拿到合适第二武器 |

这些是构筑假设，不是实测排名。不得为压低强组合而在运行时给敌人加抗性；先检查递归/多次结算，再用预先定义的倍率、内置冷却和遭遇组合平衡。
