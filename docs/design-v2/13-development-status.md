## 运行和操作

```bash
npm ci
npm run dev
# 打开终端给出的本地地址，并进入 /v2.html
```

`index.html`仍是旧版，`v2.html`才是V2战斗试作。`npm run build`同时生成两个入口。键鼠：WASD/方向键移动，鼠标瞄准、按住左键射击，Q切MCP，E技能，Space冲刺，F保存检查点，Esc暂停。手机使用左右双摇杆及界面按钮；目前以横屏进行自动化检查。

初始点的饭盆是检查点。停止移动/射击，在96范围内且周围安全时保存；刷新页面后选择“继续上次检查点”，恢复为暂停，点击继续才走世界时间。两个主动技能可在出发菜单选择。

## 架构与必要接口修正

- `StartSnapshot.runId`由宿主提供稳定的唯一标识。宿主用crypto生成元数据ID；核心战斗随机仍只有六条可保存随机流。不给seed兼任跨局身份。
- schema升级为3，core为`2.0.0-preview.2`，content为`2.0.0-preview.2`。新状态显式包含InputState与lastCommandSeq，检查点保存它们；旧版本不兼容时明确拒绝并保留原存档。
- Session使用WeakMap持有真实状态，外部只有冻结句柄。传入目录/出发快照、读取快照/视图、step返回值均与私有状态隔离。命令最多排256个，已处理ID保留最近512个，同时以持久化单调seq拒绝旧命令。
- 预览世界步是`engine/previewTick`，正式`engine/tick`仍TODO。每阶段应用changes，effects统一入队；伤害后立即声明死亡再处理下一个效果。领域事件/持久化意图显式outbox，最终commit一次。
- applySystemPlan复制工作状态和变更载荷，避免额外重复克隆；空计划不再全量复制。提交时仍执行不变量校验，调用者不能修改已发布状态。未调整60Hz、8步或1秒性能暂停阈值。
- 伤害请求必须带expiresAt；每个独立弹丸/攻击阶段有独立attackId，同一射击共享chainId。穿障与挡弹使用同一矩阵，碰撞候选按弹体/首个命中时间/目标ID处理，墙后目标不一并受伤。
- 世界状态容器的遍历若影响决定必须按稳定ID排序。当前寻路、碰撞、AI和拾取已采用稳定顺序；新增测试专门验证颠倒实体字典顺序后路线不变。
- registry区分95项设计绑定与6项当前能力；校验脚本核对每个“已实现”能力的真实函数状态，不生成空成功实例。
- 当前Canvas2D只负责独立试作的表现，不模拟另一套物理；正式Phaser适配器仍TODO。
- 保留此前createLoraTrial返回trial/nextRandom、一次计划提交二者，以及5h/DSH/LoRA的独立时间域约束。详细函数目录始终由源码同步生成。
