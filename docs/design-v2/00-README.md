## 统一术语（最新命名）

| 名称 | 用途 | 跨局保留 |
|---|---|---|
| 大白饭（Token） | 击败敌人掉落的局内经验，拾取升级并在指定等级选择插件 | 否 |
| 算力卡（GPU） | 局外技能树点数，购买永久成长和DSH槽位节点 | 是 |
| 算力碎片 | 沿用既有资源机制，5碎片兑换1张算力卡；不是局内经验 | 是 |
| 零件 | 小窝设施与永久装备/技能解锁 | 是 |

界面以“大白饭”“算力卡”为主名，Token/GPU只作括注。经验字段仍可用totalTokens等技术名称；局外余额使用gpuCards/gpuFragments，不再以rice命名。

## 用户已经确定的要求

- 唯一可操控角色是社区形象的像素大肥鱼：按用户拿铁盆参考图制作，蓝紫发、白色头饰、呆萌Q版形象，关键时刻能有惊人操作。
- 连续地图，自己游动找路；区域驻守敌人与途中追兵结合。键鼠和手机双摇杆都支持，手动瞄准射击并主动放技能。
- 局内击败敌人掉落大白饭，拾取升级；到指定等级暂停三选一插件。途中更换 MCP 武器和技能，组合可以很强、能横扫敌人。
- 局外收集资源，使用“算力卡”强化技能树，经营小窝，发现居民、伙伴、秘密和收藏。失败仍带回部分材料，局内临时成长清空。
- 局外有永久的 DSH 插件，通过击败指定难度 Boss、触发彩蛋获取；技能树特殊节点解锁 DSH 装配槽，出发前装配后全局生效。
- 难度0为Free教学，1–5为Pro并自带5h限制，6–10为Max5x，11–15为Max20x，通关15后解锁“API调用”：敌人持续生成、随对局时间增强，击败Boss不结束；5/10边界见07。
- 每级难度增加数值与新机制，高难度累计保留此前已解锁机制；API调用继承完整15级机制集。逐级表、适用条件和调度约束见07。
- 短模式目标 10–15 分钟；长模式目标 40 分钟以上。找到并击败首领后回家。
- 检查点仅保存对局进度，恢复与第一次到达时一致，无回血、刷新或重抽等额外效果。
- Claude：数量少、单体数值最高，力大砖飞，普通敌人只有同一种棕色螃蟹；Boss 封禁伙伴/技能并禁锢大肥鱼，普通控制可以连按空格挣脱，插件可以解控。
- ChatGPT：按用户截图七种Pets形象、种类和机制最多；Boss 根据条件多次重置血量和波次，玩家可理解规律破解，也可强行打穿。
- Grok：普通Grok Bot只有简单近身追赶，用人海形成压力；Boss保留简单火箭，不堆高级技能。
- 尽量把社区概念映射为真实机制。MCP 是武器；“5h限制”是限制敌人十秒内输出额度的插件；“蒸馏”能获得敌人部分属性和技能。
- Claude普通蟹按Haiku/Sonnet/Opus/Fable或Mythos递进；GPT按Astra/Sol/Terra/Luna四档（按用户列出顺序映射），七种Pets职能保留。
- DSH“更新”还是“重置”？确认每10秒随机临时更新武器或清零装备技能/冲刺/伙伴冷却，窗口持续5分钟，极小概率重设剩余窗口并提示“Reset！”；LoRA微调在每次升级进行指针训练，有完美/欠拟合/过拟合三种结果。
- 高难度加入Claude Project Glasswing的双倍控制，Grok可穿部分障碍；具体阈值/控制加倍口径/可穿标签见08。
- 社区梗可映射既有技能/插件名称与对白，不为改名擅自增添系统。
- 背景音乐使用指定的大肥鱼《Let Me Go》，不能把原创合成曲冒称原曲。

## 本方案补齐的默认决定

以下是为可实现性提出的设计，不冒称用户逐条确认：战斗数值、槽位、成长等级、首领具体招式、节点名称与花费、失败带回 40%、长模式三海域、检查点存档细节。Grok 首轮按这些初值实现并试玩，若要改变玩法方向需先反馈。

首轮不加吞食动作、不切换主角、不做多人、排行榜、每日挑战、付费系统、通用脚本编辑器或联网账号。两种模式共用系统，不复制两份实现。

## 三条设计约束

1. 社区梗要能解释机制：名字、效果、画面反馈相互对应；没有合适的梗时可用清楚的普通命名。
2. 插件让动作和规则变化，不要求凑齐四种标签，也不实时补强敌人来抵消玩家成型。不要沿用旧 `counterMult` 全局克制。
3. 先完整实现一段闭环再扩内容；小游戏试片不冒称已经完成 10–15/40+ 分钟两种模式。
