# 05 · 三阵营敌人、封禁、重置与火箭

## 1. 固定难度与形象

同一场景的敌人不读取玩家实时 DPS、插件稀有度或技能树来补强。短途基准数值如下；远征三海域按静态系数调整：生命 ×1/1.65/2.4，伤害 ×1/1.15/1.3，普通怪移速 ×1/1.03/1.06；玩家出发前可看顺序。攻击预警时长不随难度缩短。

Claude 所有敌人必须共用同一棕色螃蟹设计，不能自行扩成猫/企鹅等物种。可以通过名称、大小、脚底标记和行为区分职能；Boss 仍是同一螃蟹造型。ChatGPT 使用多个 Pets 形象，Grok 使用 Grok Bot；精确参考图需归档后制作，不凭模型印象任意改形象。大肥鱼也不能用通用鲨鱼/机器人替代。

## 2. 阵营不对称与普通敌人目录

本轮按用户截图纠正：首批9类普通敌人不是每阵营各3类，而是**ChatGPT 7类、Claude 1类、Grok 1类**。形象来源为用户提供的`image(20261024-183637).png`；截图可确认Codex、Dewey、Fireball、Hoots、Rocky、Seedy、Stacky七种Pets名称与外观，下面的战斗能力是游戏设计提案，不是这些宠物的产品功能。截图之外的宠物不凭空补名。

| 阵营 | 单体/数量 | 压力来源 | 内容约束 |
|---|---|---|---|
| Claude | 单体生命/伤害最高，数量最少 | 高血量、高护甲、重击，力大砖飞 | 普通怪只有一种棕色螃蟹；封禁/禁锢特色集中在Boss |
| ChatGPT | 单体中等，数量中等，种类最多 | 七种Pets的机制和组合 | 每种有独立轮廓、出招与反制，不只换颜色或数值 |
| Grok | 单体低血低伤，数量最大 | 追赶、占位、从多个入口持续涌入 | 普通Bot不带突进、远程火箭、封禁、爆炸或控制技能 |

### 数量与收益预算

可比较的D0基础遭遇，用约144大白饭和接近的总生命作为第一轮预算：Claude 6只（1080生命），ChatGPT 18只（按类型组合约600–1000生命），Grok 36只（504生命）。这些是整场部署总量，不是同一帧全刷；Claude同时最多2只，ChatGPT同时最多10只且最多3种，Grok同时最多24只。本地遭遇上限与01全图活敌上限同时生效，取较严格者。

预算是试玩起点，不声称三者已经等难。先比较清场时间、走位压力与承伤，再调整数量/间隔；不能为对齐种类表又把Claude/Grok扩成三种技能怪。信标、追兵和跨海域倍率保持各阵营上述方向，经验总预算仍以01为目标。

普通怪每个独立sourceId，弹体/火区沿用发射者id；死亡后的在途攻击保留来源额度。4秒内连续接触同一Grok Bot仍受01受击保护限制，不能每tick扣5血。

## 3. 精英

每海域部署2–3个固定精英事件，精英仍沿用原阵营外形与基础行为。一般生命×2、伤害×1.2、体积不超过×1.25，清晰脚底环。不得借精英词缀给普通Grok添加高级技能。

- Claude“高配实例”：只加强生命与重钳伤害，保持同一种蟹，不再有普通封锁蟹或连发束缚弹。
- ChatGPT“专长强化”：从七种Pets中选择一只强化既有能力，例如Dewey治疗两个友军，或Hoots预警后间隔0.4秒再射一发；两次射击都要清楚预警，不增加新物种。
- Grok“批量部署”：事件由3批、每批8只普通Bot组成，间隔4秒；不生成高血量/火箭/冲锋精英单体。整组最后一只死亡才结算精英箱一次；Bot保持普通4大白饭掉落，组不额外发32经验。组内成员只给普通样本，不重复加精英样本。

Claude/ChatGPT个体精英掉32大白饭、一份资源与一次MCP/技能发现机会；Grok组仅有一次精英箱（资源/装备机会），经验来自成员。所有掉落/样本账本绑定实体或groupRewardId，不能因分批出现重复发箱。不立即弹插件面板，插件只来自等级。

## 4. Claude Boss · 封禁管理员

初值：生命5000，移速70，护甲25，接触28；三阵营Boss中单体数值最高。保持棕色螃蟹形象。场地要能绕行，有清楚可见的封印物；不以细小文字提示代替预警。

招式循环按逻辑阶段调度，不同时无预警出招：

| 招式 | 预警与效果 | 破解与持续 |
|---|---|---|
| 钳制 | 前方90°扇区预警0.9秒，击中26伤并禁锢 | 正常连按Space 6次（技能树可降到5）；最多4秒自动解除 |
| 技能封禁 | 玩家脚下盖章区预警1.2秒，命中后封禁装备主动技能 | 生成3次有效基础攻击命中可破的封印物，或8秒到期；封印物被范围技能/派生弹命中不计 |
| 助战封禁 | 向当前伙伴发可躲避/可击毁封禁弹，预警0.8秒 | 伙伴封在场地装置里，3次有效基础攻击命中解除，或10秒到期；无伙伴则改为普通钳击，不自动改成必中技能封禁 |
| 批量执法 | 血量低于50%加入，三个条状区域依次预警，各1秒后钳击30伤 | 躲进相邻空隙；不是全屏必伤 |

技能/伙伴封禁各最多一个，同时封禁最多两项；一个控制结束后玩家有2秒控制免疫（可挡新禁锢，不能挡独立封禁）。被禁锢仍可普通射击，且可使用未封禁的解控技能；移动/冲刺被禁止，非解控主动技能可照常施放。技能封禁不能禁止普通攻击、插件自动解控、手动挣脱、暂停和交互UI。

连按以独立按下边沿计数，100ms内重复事件忽略，不接受浏览器键盘自动重复；触屏相同。辅助按住模式每0.2秒记一次，同样需要6次。不能把挣脱设计成无限控制：4秒上限和2秒免疫优先于所有普通控制延长。

封禁类型与禁锢分别处理：故障转移/补丁/断开连接只解控制，越狱可解技能或伙伴封禁。蒸馏获得护甲/护盾，不直接学会Boss整套封禁。

## 5. ChatGPT Boss · 重新生成

初值：生命3000，护甲0，移速95。使用经确认的 Pet 首领外形，带三枚可见“重置节点”；不把多个随机宠物拼成无法识别的形象。

常规招式：

- 分叉弹幕：预警0.8秒，向三个方向发慢泡，每枚10伤；安全通道可辨。
- 回答分支：每12秒召唤4只回响 Pet，奖励规则如下。
- 修改答案：标记两块相邻地面，1秒后其中一块爆发16伤；危险块在前0.5秒明确亮起，不做无法判断的二选一。

### 重置条件与破解

当生命第一次降到最大值55%以下、有未消耗节点、且距上次重置/打断至少10秒时，开始4秒“重新生成”读条并激活一个节点。节点位置按固定seed从三个场地位置依次使用，读条时可攻击、生命45。读条期间Boss减伤30%，仍可被击杀，不进入强制锁血或死亡后复活。

玩家可以：

1. 击毁当前节点，打断本次重置；该节点永久消耗，本体生命不恢复。
2. 在读条结束前击杀Boss，直接胜利；强构筑可以打穿。
3. 未能阻止：读条结束时消耗该节点，将Boss生命恢复到本次最大生命，重新部署本Boss定义的一组回响波次。

三枚节点都消耗后不能再重置，每局该Boss最多成功/失败合计尝试3次。生命恢复后需再次打到55%以下才符合下一次条件；打断后生命仍低于55%，10秒保护期后允许下一节点尝试。读条期间最终击杀优先于读条完成事件；同tick玩家也致死则判玩家失败（06）。

### 什么会重置，什么不会

| 对象 | 规则 |
|---|---|
| Boss生命 | 成功重置恢复，节点减少不恢复 |
| Boss攻击日程 | 从本阶段起点重新安排，旧未发攻击取消 |
| 旧敌弹/危险地面/回响 | 清除，然后在至少1.5秒明确预警后部署新回响；不能新旧瞬间叠加 |
| Boss sourceId、5h额度账本 | 保持同一个id和十秒历史，不发新额度 |
| 玩家生命、护盾、技能/伙伴冷却、装备、插件、蒸馏 | 全部保持，不恢复、不清空 |
| 大白饭、材料、地图探索、信标、检查点 | 全部保持，不能重新发奖励或刷新箱子 |
| 在途玩家攻击 | 保留，不因重置吞掉玩家输出 |

回响敌人均有蓝紫半透明标记，`rewardPolicy=none`、`distillEligible=false`，不掉大白饭/材料、不推进蒸馏。所有由此Boss召唤的敌人都执行此规则，包含常规“回答分支”，避免用召唤循环刷资源；野外真实Pet正常掉落。Boss本体只死一次、结算一次。重置不是回档，不使用全局 save/load 实现。

## 6. Grok Boss · 发射窗口

保留用户最初指定的Boss火箭，但Boss整体仍以人海为主，不能再塞地毯轰炸、火箭冲撞和复杂弹幕。初值生命2800、护甲0、移速65；本体远弱于Claude，使用Grok Bot形象与可见的简易火箭装置。

| 招式 | 行为 | 反制 |
|---|---|---|
| 批量上线（主招式） | 每12秒从两个合法入口各部署8只普通Bot，分2秒到达；Boss区域普通Bot上限24，达上限延期 | 范围/穿透清路，避免被两侧包围；全图/局部数量上限都成立 |
| 发射火箭（唯一特殊攻击） | 每8秒朝玩家当时位置瞄准1.4秒，发一枚直线慢火箭，弹速170，直击/爆炸取较高12伤、爆炸半径80，火箭生命8 | 横移或射掉，不追踪、不分裂、不连锁轰炸 |

低于50%生命时只把部署间隔从12秒改成9秒，不加新技能、不提高火箭伤害。Boss召唤Bot不掉资源/大白饭，每轮最多3只提供普通Grok蒸馏样本；部署组有稳定spawnGroupId防重复计样本。击败Boss即结束遭遇并撤走召唤Bot，不要求追清残兵。

5h限制对Boss火箭共用Boss sourceId，Bot各有独立额度。普通Bot/精英群不会发火箭，Grok蒸馏也不再从普通Bot学到Boss火箭；DSH发射许可和小火箭伙伴来自击败Boss后的单独解锁，仍可保留。

## 7. 内容验证重点

Claude：低解控构筑仍可凭走位和挣脱通关；无伙伴时不封空槽；解控插件每次有明确反馈。

ChatGPT：既能看懂条件后破解，又能以高输出在读条期间击杀；0/1/2/3次重置路径都测；读档与重置不可混用；重置不产额外奖励。

Grok：只靠大量普通Bot也能形成压力；普通/精英Bot没有远射、突进或火箭。Boss只有一项慢火箭与召集人海。扫清群怪能体现强组合，不把数量压成高血单体。

阵营横向验收：Claude最少最硬最重击；ChatGPT至少七种可辨Pet与不同机制，组合逐步介绍；Grok最多最简单。三者不能只用同一个AI换皮和倍率实现。
