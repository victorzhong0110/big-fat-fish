# 大肥鱼历险记 · 界面与美术全面改版开发规格（UI & Art Overhaul Spec）

> **给接手开发的 AI**：本文档汇总了策划与美术的全部最终拍板结论。动手前请先阅读 [AGENT.md](../AGENT.md) 与 [BRAND_GUIDE.md](BRAND_GUIDE.md)，严格遵守**“100% AI 圈黑话梗轻松爽游”**主题与 **“Q 弹粗黑边卡通像素风”** 唯一画风。

---

## 一、核心工程红线

1. **逻辑与表现隔离**：`src/v2/domain/`、`src/v2/engine/`、`src/v2/content/` 只处理确定性状态、规则与存档数据；所有 Canvas 绘制、DOM/CSS 布局、像素粒子与对话框动画放在 `src/v2/preview/`（或前端入口样式中）。
2. **已锁定原图保护**：不得覆盖 `public/art/characters/` 原有立绘及 `approved-art.json` 的既有校验记录。
3. **素材采购原则**：海床地砖、珊瑚礁、木箱、UI 边框、小图标优先使用 **CC0 / 开源像素素材**（对齐粗黑边 Q 版像素风，渲染关闭抗锯齿 `imageSmoothingEnabled = false`），**严禁**引入高清二次元插画或写实照片材质。
4. **交付前必跑全绿**：
   ```bash
   npm run sync:v2    # 若修改了 V2 公开函数导出或签名
   npm run check:v2   # TS 类型检查 + 架构依赖 DAG 检查
   npm test           # Vitest 单元测试
   npm run build      # Vite 生产构建
   ```

## 二、五大模块详细开发规格

### 模块 1：游戏大厅主页（合并原标题页与模式入口）

**布局参考**：《明日方舟》卫戍协议主界面结构 + 《植物大战僵尸》大肥鱼元素艺术字标题，整体换皮为 **Q 弹粗黑边深海像素风**。

1. **背景层**：干净的像素海洋背景——缓慢上浮的像素气泡 + 轻轻摇晃的像素海草。**不在画面上单独摆放大只静态立绘或 Boss 剪影。**
2. **正中主标题**：定制 **融入大肥鱼元素的像素艺术字 Logo**（《大肥鱼历险记》，胖嘟嘟像素字形 + 鱼鳍/鱼尾/泡泡装饰 + 粗黑描边），参考《植物大战僵尸》主标题的辨识度。
3. **右上角**：双入口按钮牌——**「小窝家园」**（进入模块 4 可移动海底大厅）与 **「AI 科技树」**（直达模块 5 横向科技树，亦可从设置/图鉴旁进入）。
4. **左上 / 左下角**：轻量状态牌，展示成就统计、算力卡/零件余额、图鉴与社区模组/设置入口，不挤占中间主视觉。
5. **右下角（核心出发区）**：
   - 上方：一条 **药丸形/滑槽式 3 档模式切换器**，三档分别为：**`剧情 | 探索 | 无尽`**（Free 教学首通后移入角落小入口）。
   - 下方：醒目的主按钮（如 **`▶ 选择难度 / 出发`**），点击后**跳转到模块 2（Benchmark 难度页）**。

### 模块 2：模式规则与纵向 Benchmark 难度页

1. **三大模式与解锁联动（`src/v2/domain/` & `content/`）**：
   - **剧情模式**：按章节推进，挑战三大阵营 Boss。
   - **探索模式（搜打撤玩法）**：
     - 局内主打**搜刮物资（宝箱/补给/大白饭/算力卡）→ 战斗 → 在撤离点读条撤离带回奖励**；若阵亡则损失本局未撤离战利品。
     - **难度与解锁硬规则**：Benchmark 难度越高，探索模式掉落倍率与奖励品质越好；**只有在「无尽模式」中通关/完成对应 Benchmark 难度，才能解锁「探索模式」的该对应难度**。
   - **无尽模式**：持续爬层挑战，用于冲榜并解锁探索模式的对应难度阶梯。

2. **Model 等阶顺序修正（重要 Bug 修复）**：
   - 修正 `src/v2/domain/difficulty.js` 中 ChatGPT 等阶顺位：**`Astra` 为最强旗舰**，1–15 级从弱到强顺序必须为 **`Luna → Sol → Astra`**：
     - **Lv.1–5**：ChatGPT `Luna` / Claude `Haiku`
     - **Lv.6–10**：ChatGPT `Sol` / Claude `Sonnet`
     - **Lv.11–15**：ChatGPT `Astra` / Claude `Opus`（API / 隐藏极限档保留 `Fable / Mythos`）

3. **Benchmark 难度页布局（参考《明日方舟》规程等级界面）**：
   - **右侧**：**纵向可滚动的 Benchmark 1–15 列表**（纯数字跑分数值，每 5 级切换一次段位徽章与主题色；未解锁项带锁标识，当前选中项高亮并在左侧显示「当前选择」指向标签）。
   - **左侧主区**：展示当前选中 Benchmark 等级对应的**敌方模型阵容徽章**（如 `GPT Astra · Claude Opus`）与本级词缀说明。
   - **底栏**：左下角显示当前**奖励获取倍率与敌方强度**（如 `奖励 145% · 强度 +13`），右下角为 **`▶ 开始整活`** 按钮。

### 模块 3：局内战场、像素素材与 HUD

1. **海床与场景物件（`src/v2/preview/view.js`）**：
   - **海床地面**：低对比度青蓝 `32×32` 像素地砖平铺（浅水波、海沙纹、少量像素小气泡），绝不使用暗灰写实纹理，确保弹幕与红圈预警一目了然。
   - **障碍与道具**：优先采用 CC0 像素素材库的**珊瑚礁、沉船木箱、贝壳**（仅少数彩蛋障碍做成冒泡破显卡/断网路由器，不强行全员硬件化）。
   - **核心交互点**：工作区信标做成像素信号浮标（进圈显示“工作中”）；探索模式宝箱做成粗黑边像素宝箱，撤离点做成发光的**像素气泡传送柱/小潜艇**。
2. **闲置原图全接入**：
   - 将 `public/art/characters/bsod.png`（蓝屏）与 `null-signal.png`（断网）正式接入**探索模式（搜打撤）的高价值守卫怪 / 干扰精英**，消灭所有无贴图纯色方块怪。
3. **极简 HUD 与克制提示**：
   - 左上角保留《元气骑士》式紧凑三连条（HP / 护盾 / 大白饭进度），右上角保留小地图与暂停钮；主角脚下保留**状态环 + Boss 方向楔 + `F` 提示**。
   - **去掉无意义头顶随机废话气泡**（AI 梗通过机制与视觉自然体现，不做硬塞文字的廉价玩梗）；**彻底禁止左下角常驻大弹窗遮挡操作**，重要事件仅在顶部中央做轻量单行提示。

### 模块 4：小窝家园（可操作大肥鱼自由移动的大厅）

从大厅右上角进入「小窝家园」后，渲染一个**一屏（或微滚动）可自由游动的像素海底房间**：
1. **自由移动**：玩家用 `WASD`（手机端左摇杆）直接操控大肥鱼在房间里游动，右上角常驻「返回大厅」按钮。
2. **房间互动设施（靠近按 `F` 或点交互钮）**：
   - **已解锁伙伴**：饭团、补丁、小缓存、路由员、替身进程、小火箭在各自角落待机，走近按 `F` 在**屏幕下方弹出经典像素 RPG 对话框**（左侧带伙伴 Q 版头像 + 专属搞笑对话 + 「带它出战」切换按钮）。
   - **试射靶桩 / 沙袋**：方便玩家出发前随时开火测试泡泡炮、新 MCP 武器与打击感特效。
   - **大白饭小餐桌 / 算力展示角**：展示当前算力卡、大白饭与家园设施加成。
   - **AI 科技树终端**：按 `F` 直接打开模块 5 的横向科技树。
   - **模组架 / 图鉴台**：按 `F` 打开社区模组或图鉴面板。

### 模块 5：《文明6》式横向扩展科技树

推翻现有简陋竖排列表，做成**可横向拖拽/滚轮滚动的《文明6》风格横向科技树面板**（`src/v2/preview/nestManager.js` + `src/v2/content/catalogData.js`）：

1. **4 个 AI 梗横向时代列（从左到右演进）**：
   - **时代 I · 预训练（Pre-train）**：基础生存、基础射速、基础移动、探索视野。
   - **时代 II · 微调（Fine-tune）**：流派分叉（重炮高伤 vs 极速泼水、护盾续航 vs 冲刺机动、工作区提速 vs 搜刮掉率）。
   - **时代 III · 对齐（RLHF / Alignment）**：引入**跨线双前置节点**（真正体现《文明6》取舍感，例如需要“干饭 + 射击”双前置的《上下文吃撑：捡饭短时加攻速》、需要“探索 + 技能”双前置的《搜打撤专家：撤离加速+额外带回战利品》）。
   - **时代 IV · 全量涌现（Emergence）**：终局质变大节点（如《我还能游》免死一次、《DSH 槽位扩容》、《开局自带 1 枚白银海克斯》）。
2. **连线与交互细节**：
   - 每个节点为 Q 弹粗黑边横向卡片（左侧像素图标 + 节点名 + 简短效果 + 算力卡费用），节点间用**正交折线 + 箭头**连接。
   - 清晰三态：**已点亮（亮蓝/金边） / 可解锁（呼吸高亮） / 未满足前置（暗灰带锁）**。
   - 鼠标悬停或点击任意节点时，**自动高亮其完整前置依赖路径**；顶部保留算力卡余额、路线筛选标签和「免费重置整棵树」按钮。

## 三、建议分步实施顺序（给开发 AI 的执行节奏）

1. **Step 1（核心规则与底座）**：修正 `difficulty.js` 的 `Luna → Sol → Astra` 顺位 + 实现“无尽通关对应 Benchmark 解锁探索（搜打撤）对应难度”及搜打撤结算逻辑 + 接入 `bsod.png` / `null-signal.png` 精英。
2. **Step 2（大厅主页 + Benchmark 难度页）**：按模块 1 & 2 重构 `v2.html`、CSS 与 `host.js`（确保手机端同步适配）。
3. **Step 3（局内像素海床 + HUD 清理）**：接入 CC0 像素地砖/道具贴图，清理头顶随机废话气泡与左下角遮挡，完善探索撤离视觉表现。
4. **Step 4（小窝自由移动家园 + 文明6横向科技树）**：实现小窝可移动房间、试射靶桩、下方 RPG 对话框与 4 时代扩展科技树。
