# Let Me Go

User-supplied 大肥鱼 original MP3, 4,979,565 bytes, split into seven consecutive binary parts for reliable repository transfer. These parts are not separate playable tracks. No transcoding or trimming is applied.

`node scripts/prepare-v2-audio.mjs` concatenates them into `public/audio/let-me-go.mp3` and verifies SHA-256 `8d32f1a0ed25035584a6bc804ea6fc22488bcff99e691f33b87e360d4cb8e15f`. The dev/build hooks run this automatically. The original source is not covered by the game's code license.
